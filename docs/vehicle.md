# 实车规格与仿真对照

实车为 ROS2 EDU KIT PRO（Scout Mini 底盘 + RS-Helios 16P + RealSense D435）。
下表把厂家规格与仿真模型 `src/scout_mini_sim/urdf/scout_mini_rdk.urdf.xacro`、
导航配置 `src/scout_mini_navigation/config/nav2_params.yaml` 逐项对照，供上实车时参考。

## 上实车前的待办

1. **测量安装位置**：雷达和 IMU 相对车体中心的位置与朝向、相机前后位置与俯仰角，更新 URDF。
   雷达高度变化时，同步 FAST-LIO 外参 `extrinsic_T` 和 `pcd_to_grid.py --sensor-height`。
2. **雷达驱动**：`rslidar_sdk` 输出带逐点时间的点云。仿真专用的设置要改回去：FAST-LIO 的
   `preprocess.instantaneous_scan` 改为 `false`；三维定位可考虑开启 `use_continuous_time_deskew`。
3. **标定等效轮距**：滑移转向在不同地面上打滑程度不同，需用实车重新标定 `wheel_separation`，
   或依靠 EKF 中的 IMU 航向。
4. **传感器协方差**：真实轮速和 IMU 有噪声与零偏，EKF 需要合理的协方差（仿真中为 0）。
5. **在实车上重新建图**：用 FAST-LIO 建 PCD，再用 `pcd_to_grid.py` 转二维栅格，两者同名放在 `maps/`。
6. **安全**：底盘只有电机制动；先在低速（如 0.3 m/s）下验证定位、避障和停车，再逐步提速。
